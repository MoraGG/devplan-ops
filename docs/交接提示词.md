# 项目交接提示词（复制整段给新会话）

你在接手一个已开发到 v0.2 的 Web 应用项目：**房地产开发运营计划系统（代建三级计划管理）**。仓库即当前目录，全部代码、数据库、文档都在里面，开箱即跑。请先读完本提示词再动手。

## 一、项目背景与目标

代建公司"代建运营部"用它管理住宅开发项目的进度计划。计划体系为四级：**里程碑 / 一级 / 二级 / 二级\***（对应 Excel 里的 里程碑/一级/二级/三级）。节点日期不是手填的，而是由**相对工期引擎**按"依赖节点 ± 偏移天数"推算，并支持按项目参数（层数 topfloor、精装/毛坯 delivery、开发贷 devloan 等）自动选分支。规则源头是仓库根目录的《远建2026版三级计划（绿城基础含公式）.xlsx》，需求文档见《房地产开发运营计划系统_需求规格说明书_v0.2.md》，设计说明见 db/design.md。

## 二、技术栈与启动方式

- Flask + SQLite（预留 MySQL：`DB_TYPE=mysql`，MySQL 方言 DDL 在 db/01_ddl.sql）
- 启动：`pip install -r requirements.txt` → `cd app && python3.11 app.py` → 打开 http://127.0.0.1:5000
- **不要重建数据库**：db/devplan.db 开箱即用（含标准节点库、参数化规则、演示项目、变更日志）。db/02_seed.sql 里**没有** std_node_rule 数据——参数化规则是 db/extract_rules.py 从 Excel 提取后写入 DB 的，重建会全部丢失
- 关键代码：
  - app/app.py —— 全部路由 + 规则编辑 + 变更日志（约 22 个函数）
  - db/engine.py —— RelativeDateEngine 相对工期引擎，resolve() 逐分支匹配 AND 条件（卡间 OR），支持 is_default 兜底
  - db/dbconn.py —— 连接层（SQLite/MySQL 双模式，busy_timeout=5000）
  - app/templates/ —— 项目详情（含编辑节点弹窗）、标准库、规则编辑器等页面

## 五、注意事项（前人踩过的坑，务必遵守）

- **SQLite 写锁**：log_rule_change(scope, std_node_id, project_id, action, before, after, con=con) 在未提交事务内调用时**必须传调用方的 con 复用连接**，否则另开连接必报 database is locked；写日志前用 rules_snapshot() 取 before 快照
- **WAL 不要开**：部分沙箱环境下 WAL 遗留 -wal/-shm 锁文件导致假死锁，当前用 DELETE 日志模式，保持现状
- **验证方式**：用 Flask test_client 独立进程跑（参考之前做法：appmod.app.test_client()），四种场景各验证一遍——标准库保存、项目级 fixed / rule / inherit，各自应写 rule_change_log 且 GET 返回 logs
- **不要 pkill -f "app.py"**：会误杀执行命令的 shell 本身，清端口用 `fuser -k 5000/tcp`
- 分支保存必须经 sanitize_branches() 清洗；前端分支数据结构见 app/templates/project_detail.html 的 addBranch()
