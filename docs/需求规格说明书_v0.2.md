## 0.5 模板来源与对齐说明（重要）

本系统的节点体系**直接对齐你提供的绿城管理标准模板**《远建2026版三级计划（绿城基础含公式）.xlsx》，该模板是行业代建标杆，包含：

- **「前置信息」表**：11 项项目参数，用于选取标准期量。
- **「节点计划(终稿)」表**：148 个节点（里程碑 13 + 一级 40 + 二级 89 + 三级 6），含相对工期公式、三版完成时间、集团标准期量、成果表单与支持性文件。其中 **Excel 的「三级节点」= 系统侧的「二级*」节点**。
- **「Sheet2」**：项目级时间基准（项目启动 / 计划交付 / 总工期）。

> 这意味着：系统的"标准节点库 + 标准工期库"可**直接由该模板初始化**，无需从零设计，大幅降低 MVP 落地成本。

## 1. 项目背景与定位

代建运营部统筹多个住宅代建项目。现状依赖 Excel 在各项目、各部门间传递，存在**版本不统一、进度不透明、预警滞后、计划与投资测算脱节**等问题。

**系统定位**：代建总部对多项目开发计划进行「编制—审批—跟踪—预警」的中枢平台，并为投资测算团队提供可复用节点/工期数据。

**核心价值主张**
- 用**标准工期库 + 模板**替代从零编制（模板已具备）；
- 用**结构化计划数据**替代 Excel，版本可追溯、跨项目可汇总；
- 用**自动偏差计算 + 预警**替代人工盯表；
- 用**节点数据**支撑投资测算（货值、回款节奏）。

## 4. 计划管理体系（核心 · 基于模板实证）

### 4.1 四级节点体系（里程碑 / 一级 / 二级 / 二级*）

| 层级 | Excel 类别 | 数量（模板实测） | 典型内容 | 管控重点 |
|---|---|---|---|---|
| L0 | 里程碑 | **13** | 经营策划会、施工证、预售证、首开、封顶、竣工备案、交付 | 关键节点、对外承诺 |
| L1 | 一级 | **40** | 跨职能主线节点（设计、工程、招采、营销…） | 跨职能协同节奏 |
| L2 | 二级 | **89** | 各职能线落地任务（Excel「二级节点」列） | 落地执行、资源排布 |
| L2* | 二级*（= Excel 三级节点） | **6** | 挂在一级/里程碑下的更细任务：外立面深化图、总包重计量、粗装修完成、配套验收证明、联合验收完成、室内外改造 | 精细化管控 |

> ✅ **已澄清（重要）**：层级映射为——Excel 里程碑→系统里程碑、Excel 一级→系统一级、**Excel 二级→系统二级(89)**、**Excel 三级→系统"二级*"(6)**。系统共**四级**：里程碑 / 一级 / 二级 / 二级*。

**13 个里程碑节点（模板实测清单）**

```
经营策划会 → 取得规划建筑设计方案批复 → 取得《建筑工程施工许可证》
→ 施工图版目标成本审批完成 → 销售展示中心开放 → 首个样板房/区开放
→ 取得首批次《预售许可证》 → 项目首开 → 完成整体正负零施工
→ 主体结构封顶 → 完成外架/吊篮拆除 → 取得《竣工验收备案证》 → 项目计划交付
```

### 4.5 工期推算引擎（将 Excel 公式转为系统模型）

Excel 中 148 个节点（里程碑13 + 一级40 + 二级89 + 三级6）全部用公式 `=L基准行 ± 天数` 推算，例如：

| 公式 | 含义 |
|---|---|
| `=L6+30` | T0（项目启动，第6行）后 30 天 |
| `=L25+30` | 依赖第 25 行节点，其后 30 天 |
| `=L82-150` | 依赖第 82 行节点（样板区开放），其**前** 150 天 |

**系统建模建议**：将"相对工期公式"抽象为 `依赖节点 + 偏移天数 + 基准类型`：
- 基准类型：T0 基准 / 某节点基准
- 偏移：+N 天（之后）或 −N 天（之前）
- 由此自动推算每个节点的计划时间，替代手工维护公式。

### 4.6 三版计划（代建核心管控逻辑）

每个节点维护 **三套完成时间**，对应不同管理诉求：

| 版本 | 字段 | 用途 |
|---|---|---|
| 内控版 | 内控开始/完成 | 项目内部自我管控 |
| 考核版 | 考核版完成 | 对集团/区域考核口径 |
| 履约版 | 履约版完成 | 对委托方合同履约承诺 |

> 系统应支持三版并存、对比，预警可分别针对三版设定阈值。

### 4.7 项目级时间基准（Sheet2）

- 项目启动日、计划交付日、总工期（月数，公式 `(交付-开工)/30`）。
- 作为整个项目计划的锚点（T0 实际落位）。

## 9. 非功能需求（初拟）

- **性能**：百级项目、万级节点下看板秒开；甘特图流畅。
